# SEO Practice Site: Kettle & Crema (fictional coffee roaster)

Deploy free on GitHub Pages, Netlify or Cloudflare Pages, then replace `https://example.com` everywhere with your real URL.

- `index.html` is mostly done right: use it as a reference (title, meta description, canonical, Open Graph, JSON-LD, alt text, heading order).
- `blog/pour-over-guide.html` is **deliberately full of SEO problems**. Find and fix them.

## Exercises
1. Page title is useless; write a unique, keyword-led one (under ~60 chars).
2. Add a meta description and canonical link.
3. Two H1s plus a skipped heading level (h1 > h3): fix the hierarchy.
4. Image has no alt text, width/height, or descriptive filename.
5. Missing `lang` attribute and viewport meta tag.
6. Weak anchor text ("click here"): make links descriptive.
7. Add Article + BreadcrumbList structured data.
8. Add the blog page to `sitemap.xml`.
9. Add Open Graph tags.
10. Run Lighthouse and PageSpeed Insights before and after; compare scores.
11. Connect Google Search Console and submit the sitemap.
12. Stretch: add 3 more pages and build internal links between them.
